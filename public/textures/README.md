# Landmark materials

`brick-wall.jpg` is the unmodified 1K diffuse image from Poly Haven's
[Brick Wall 001](https://polyhaven.com/a/brick_wall_001), licensed
[CC0](https://polyhaven.com/license).

Download: https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/brick_wall_001/brick_wall_001_diffuse_1k.jpg

This is a generic photographed masonry material, not a photograph of the
Copenhagen landmarks. The map uses it for buildings tagged as brick in OSM.
Building geometry and heights still come from OpenFreeMap/OpenMapTiles.
The six landmark footprints and names in `src/data/landmarks.json` come from
OpenStreetMap (ODbL 1.0); individual source URLs are recorded in that file.

`dr-logo.svg` is the Danmarks Radio wordmark from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Danmarks_Radio_logo.svg). `dr-logo.png` is its local, renderer-compatible PNG conversion. It is used only at the mapped DR Byen location (OSM way 25520993). DR remains the trademark owner.

`fields-logo.png` is the current transparent PNG from [Field's official website](https://fields.steenstrom.dk/.netlify/images?url=https://img.uniform.global/p/hwzO26lASzePZ9R51iN_MQ/u9VLRKGASxyAgMy0-tA09Q-fields-tagline-main-logo-h-n.png), resized locally for the map renderer. It is used only at Field's mapped location beside Ørestad station (OSM relation 20346870). Field's remains the trademark owner.

`royal-arena-logo.png` is the Royal Arena mark supplied in this project conversation. It is used only at the mapped Royal Arena location (OSM way 391594117). The warm terracotta façade treatment follows the description in the [Danish Architecture Center profile](https://dac.dk/en/magazine/places/royal-arena-285); Royal Arena remains the trademark owner.

`christiania-logo.jpg` is the Christiania mark supplied by the user in this project conversation. It is used only at the mapped Christiania centre near Christianshavn. The lights and canopy icons are illustrative map details, not a survey of the area.
